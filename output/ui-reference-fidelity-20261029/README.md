# 宝蓝视觉整页参考

使用内置imagegen生成，承接上一组`output/ui-reference-20261029/`参考图。完整提示词见`prompts.json`。

- `business-reference.png`：业务票单、状态标签、筛选表格与详情布局。
- `packing-results-reference.png`：装箱结果、清爽三维视图与方案摘要。
- `admin-reference.png`：后台数据卡、图表与审计表格。
- `login-reference.png`：港口摄影与独立登录表单。

统一宝蓝色、深墨文字、淡蓝画布，Inter Variable与Noto Sans SC Variable字体，以及细线SVG图标。参考中的统计、日期、船名、文件、联系人、机构及方案均属示意；真实产品不填充这些数据，不创建无功能操作。代码保留已有业务、身份权限、原始来源核验和运输事件证据。

登录场景另由内置imagegen依据整页参考重建为纯摄影概念图，去除界面和文字后用于实际页面。该场景不是公司场地的纪实照片。
