- `smart-import-reference.png`：分模式导航、上传来源、清单核对与可选截图核验。
- `public-product-reference.png`：摄影场景与文字面板组合的详情页，包含概览、能力、流程、应用场景和常见问题。

图中的模拟单号、日期、联系人、地址、电话、运输状态和功能演示均不是公司事实，不作为代码数据、联系方式或能力承诺。实际版本保留已确认的公司信息、真实来源文件与后台数据；未报告的运输节点不补造。

提示词要点：中文logisticspluscn物流平台；白底、浅蓝灰页面、海蓝文字及小面积暖橙；统一展开侧栏，右侧切换内容；专业可读表格、原始来源核对、冲突阻断；官网采用成熟企业的editorial章节，避免暗底、大渐变、虚构指标与客户背书。
