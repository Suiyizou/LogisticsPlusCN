# 统一智能导入验收样本

本目录仅含合成测试数据，没有客户业务文件或模型密钥。

- `packing-dual-exact.xlsx` 与 `packing-dual-exact.png`：同一份清晰单包装清单，可在智能导入入口上传Excel，再附加原图进行交叉核对。
- `expected.json`：模型调用前确定的标准答案。
- `acceptance.json`：实际模型任务的字段比对、正反例及预览模型通路验收摘要。
- `browser-acceptance.json`：实际页面对人工确认、字段冲突和原有数据保留的验收。

标准清单为P01、SAMPLE-A、MD-A，1件，120×100×150cm，150kg，普通包装，可堆叠，无保持朝上约束。来源合计为1件、150kg、1.8m³。

这些结果只证明本组合成样本与阻断行为已验证；不能据此推断复杂文件或低清图片的普遍准确率。样本没有写入原有业务货物清单。
