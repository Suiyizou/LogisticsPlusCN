## 已落地的结构

- 票单详情直接测试生产 composable，不再解析 Vue 源码后在 VM 中拼装函数。API、提示、确认框等通过依赖传入，Vue 的真实 watch 与 effectScope 仍参与测试。
- 图表的数据汇总仍属于业务页面；图表组件只接收趋势、构成、资源和状态数据。组件内部处理空数据、语言变化及减少动画设置。
- 图表卸载会注销尺寸监听、断开 ResizeObserver、取消排队的 animation frame，并释放实例。晚到的回调不能重新绘制已销毁的图表。
- 票单作用域关闭会中止活动中的船司请求；晚到的读取或写入响应不能修改已离开的详情页。

目录、客户表单与票单列表的状态已在第三批移至功能模块，客户导入、代理及交接流程在第四批抽出，手工建单、票单 Excel 导入及个人资料逻辑与弹窗已在第五批抽出。第七批迁移客户目录/详情、票单详情及批量追踪/业务字段弹窗的页面模板；第八批迁移客户弹窗与代理/交接页面、弹窗及样式。第九批迁移独立总览与客户域组装，第十批迁移票单组装、票单合同及列表写入，第十一批迁移客户/代理/交接合同与纯票单展示规则。原页面仍持有翻译包装、服务/导航适配和部分历史样式。格式化会改变物理行数，不能用 Vue 文件总行数来代表逻辑缩减或运行性能提升。

### 第二批：批量任务、导航和 Vue 脚本检查

- 后台任务不再由弹窗中的零散函数管理。创建和冲突检查互斥，导入提交使用检查前固定的客户、票号、渠道和发布设置；刷新任务也支持在创建响应返回前请求停止。
- 关闭弹窗继续观察后台任务；离开页面清理轮询和计时器，晚到的请求不能恢复轮询或改写停止状态。创建响应若在离开后返回，仍保存任务 ID，且不会覆盖另一页面已记住的新任务。
- 任务 ID 继续使用原有按登录用户隔离的 localStorage 键。403/404 停止恢复，临时网络失败延迟重试；终止事件只刷新票单一次。浏览器存储不可用时，后台任务照常运行。
- Excel 解析使用独立版本号，换文件、清空及卸载都会让旧解析失效。先读取原生 FileList，再清空 input，避免清空后拿不到文件。删除原页面未使用的批量文本状态和重置函数。
- 侧栏、合法 section 和默认落点共用同一角色配置。Vue Router 处理菜单、客户详情与票单详情；页面监听路由变化，支持刷新、前进和后退。旧 `?shipment=...` 及 `?customer=...` 链接仍可用，删除详情对象会替换为列表 URL。
- 导航加载携带当前位置有效性检查，客户目录响应在应用前验证请求版本，避免快速切换客户后旧响应重新选中之前的客户。客户目录与表单整体仍未抽成独立模块。
- 详情按票单 ID 独立读取，不再因票单不在当前分页/筛选结果中而清空选择；403/404 由详情接口确认后才移除详情链接，临时网络错误保留当前选择。
- 质量门新增 Vue **JavaScript 脚本**绑定检查，通过当前安装的 Vue SFC 编译器处理 setup 宏，再执行 `no-undef`；缺失的页面辅助函数可以在构建前被发现。修复取消刷新提示中的未定义 `clearPageMessage` 调用。

本批未改变后端任务 API、调度刷新策略或数据库结构。新增的导航测试使用真实 Vue Router 内存历史与 Vue watch，没有执行浏览器 DOM 端到端验收。Vue 模板和 TypeScript SFC 的完整类型保护仍待后续补齐。

### 第三批：客户目录、表单和票单列表

- 客户目录持有检索、分页、勾选、客户选择、关联票单和关联客户。切换客户立即清空旧资源；每个读取请求验证版本、客户选择和导航有效性，旧响应及旧错误不能更新新客户。
- 目录请求不会把用户刚选中的 B 客户重新切回原先指定的 A。成功写入客户资料或删除客户会让更早的目录读取失效，避免旧响应恢复已保存前的资料或已删除客户。
- 创建、档案保存、停用/启用、删除、密码重置、客户码补录及关联客户保存有统一的写操作互斥状态。提交时固定客户和字段；切换客户不会让旧请求修改新客户的编辑区、关闭新对话框或显示旧密码结果。
- 后台目录刷新保留同一客户尚未保存的编辑内容；切换客户才初始化另一份表单。创建完成后直到关联目录刷新结束仍保持提交锁，防止前一次 finally 释放后一次提交的状态。
- 批量删除等待每个请求结束后再汇总：成功客户从本地列表移除并刷新客户和票单，失败客户保留勾选并显示部分成功说明。全部失败时保留原列表，不报告全部成功。
- 票单列表独立持有服务端筛选和分页，使用请求版本与查询条件共同验证响应。过滤条件变化清空旧勾选并回到第一页；接受服务端因删除而修正的页码，刷新后用新行对象替换已选中的旧对象。
- 快照标准化和总览去重移到纯函数模块，保留 envelope、JSON 快照和原字段优先的兼容规则。客户/代理分页共用纯分页函数；分页动效计时器在作用域结束时清理，连续翻页只保留最新计时器。

第三批新增 36 项前端行为测试，直接使用生产 composable 和真实 Vue watch/effectScope；截至该批共 106 项。API 路径、后端角色范围、业务字段、数据库及自动刷新调度均未修改。各弹窗模板仍在父页面，尚未完成全部大页面拆分；没有把单元测试视为浏览器 DOM 或真实船司验收。

### 第四批：客户导入、代理管理与客户交接

- 客户导入独立管理快速录入、Excel 预览、提交与账号结果。快速录入也执行服务端的 500 行上限；解析文件时不能提交，替换文件、切换模式、关闭或卸载让旧解析失效。原生 input 在捕获文件后立即清空，允许再次选择同一文件。
- 客户批量导入、客户资料写入、代理维护和交接共用客户写锁，直到关联列表刷新完成才释放。提交参数复制为固定快照，处理中禁用相关表单和关闭按钮；晚到响应不能修改已卸载工作区。
- 代理目录独立管理请求版本和分页。账号创建后刷新代理目录；修改名称、启停、删除和改密互斥。中英文导入模板可通过同一解析器读取，账号规则与服务端 200 行上限保持一致。
- 批量代理创建优先使用批量接口，只有 404/405 才回退到最多三个逐条创建 worker。逐行保留创建成功与失败结果；卸载停止派发排队中的创建，已经提交的服务端写入不会被视为已取消。其他网络/服务端错误保留预览，由用户核对后决定是否重试，不自动再次创建账号。
- 账号创建表单、批量代理预览及客户账号结果中的密码在完成、关闭或卸载时清理；账号结果导出只在本次结果仍有效时写出。导出使用固定的字段与翻译快照，不将密码写入持久化存储。
- 业务员直接交接和海外代理分配保留不同接口、角色范围和接收人规则。交接请求固定客户、接收人和原因，成功后立即移除源工作区中转出的客户，并刷新客户、票单、接收人和交接记录；管理员代理分配仍保留客户目录。刷新不清除用户后来选中的其他客户。
- 交接记录继续使用服务端从 0 开始的页码；筛选、翻页和尺寸变化验证请求版本与查询条件，接受服务端修正的分页。旧错误不能关闭新分配弹窗，旧弹窗的关闭回调不能清空已经重开的交接表单。

新增 `customer-operations.test.mjs` 42 项，使用生产 composable、Vue effectScope 及真实 XLSX 表格；前端功能模块共 148 项。测试覆盖提交互斥、解析/列表乱序、角色限制、交接目标固定、部分导入失败、worker 中断、凭据清理和双语模板往返。模板 DOM、真实账号登录及服务端交接仍需端到端验收；本批未修改后端、数据库或定时刷新策略。

### 第五批：手工建单、票单 Excel 导入与个人资料

- 手工建单和 Excel 导入共用写锁，覆盖冲突检查、确认、提交及列表刷新；期间禁用相关操作。固定客户、发布设置和票单参数，避免异步过程中改绑客户或覆盖用户后来修改的字段。
- 保留覆盖已有票单的明确确认；Excel 沿用 300 张票单、10MiB 文件及最多 4 个提交 worker。文件解析、导出、关闭、账号变化和卸载都验证各自会话版本，旧结果不能回写新弹窗；输入捕获 File 后清空，支持重新选择同一文件。
- 已发出的写请求不会被宣称取消。客户授权变化停止排队中的请求，尚未提交的行标为 NOT_SUBMITTED 并保留已提交结果。创建成功而列表刷新失败时提示刷新失败，避免误报创建失败而重复建单。
- 两个受控票单弹窗只使用同一生产 workflow，无第二套业务状态。组件持有 scoped 样式、焦点循环与恢复、背景滚动锁及忙碌时的关闭约束；修复实际 390px 浏览器验收发现的盒模型溢出，并让底部操作区保持可用。下拉框先处理自身键盘事件，文本字段的 Escape 可关闭弹窗。
- 个人资料与改密独立管理提交锁和账号会话；旧响应不能修改切换后的用户。显示名称提交成功更新应用及存储，密码仅保存在当前表单，关闭或卸载清理；不保存到共享持久状态。
- 新增手工建单/导入 30 项、个人资料 14 项生产逻辑测试。旧 Excel 检查移除已过期的内联函数正则断言，保留真实表格往返和接口/组件接线检查，行为由生产 composable 测试覆盖。

浏览器验收使用本地真实 Vue 页面和拦截 API 的业务员测试数据：手工必填校验及创建、客户选择、Excel 多工作表预览/提交/结果下载、显示名称更新、改密校验与凭据清理、键盘焦点及桌面/390px 布局；业务员详情 URL、返回和刷新，以及海外代理无建单/导入/编辑入口。截图及测试替身保存在忽略目录 output/playwright/framework-batch-five/。没有操作生产账号、真实船司、服务端数据库或线上部署。
