# DrewesLogistics 三个平台功能说明

## 1. 账号与角色

内部系统只保留三种角色：

| 角色 | 数量与职责 | 主要权限 |
| --- | --- | --- |
| 管理员（`ADMIN`） | 系统管理员，可有多个 | 管理内部账号、登录设备、系统配置、票单业务文件和审计记录 |
| 业务员（`BUSINESS`） | 全系统仅保留一个 | 负责全部客户、票单、船司更新、发布、海外代理和业务分配 |
| 海外代理（`OVERSEA_AGENT`） | 内部协作账号，可有多个 | 只处理分配给自己的客户及票单细节，包括备注、文件和留言 |

外部客户使用独立的客户登录通道，不属于内部三角色。客户只能读取业务员已经授权并发布给自己的数据。

管理员、业务员和海外代理都可在个人信息页修改显示名称及自己的密码。修改密码时必须先验证当前密码；修改成功后保留当前设备会话，其他设备退出登录。

## 2. 内部货单运营与追踪平台

### 2.1 管理员后台

- 内部账号管理：创建、编辑、重置密码、启用或停用账号。
- 管理导航：采用白色侧边导航，并保留“员工管理”作为三类内部账号的统一管理入口。
- 唯一业务员约束：系统拒绝创建第二个 `BUSINESS` 账号。
- 平台信息：按客户展示负责业务员、业务员分配的海外代理、客户用户名、客户码、客户身份、状态和业务票单数量。
- 设备管理：查看账号登录设备、IP、登录时间、在线状态，并执行下线或删除设备记录。
- 票单业务文件：查看长期关联到票单的文件与上传记录；管理员后台不再展示“工作区临时文件”模块。
- 系统监控：账号数量、在线设备、登录成功/失败、接口访问统计和服务状态。
- 详细审计：
  - 时间、用户 ID、用户名、角色；
  - HTTP 方法和接口路径；
  - HTTP 状态、成功/失败、处理耗时；
  - IP、浏览器/设备标识、请求关联编号；
  - 业务动作、目标类型、目标 ID 和操作说明。
- 审计不保存密码、令牌、Cookie 或请求体中的敏感内容。

### 2.2 业务员工作台

导航收敛为：

1. 总览
2. 客户管理
3. 票单管理
4. 批量追踪
5. 海外代理
6. 个人信息

客户管理：

- 单个创建和 Excel 批量导入客户。
- 编辑客户资料、重置客户密码、维护 6–10 位全局唯一客户码。
- 客户列表直接提供“为该客户分配代理”或“为客户更换代理”按钮。
- 分配窗口只展示可用海外代理，采用客户 → 代理的单向分配流程。
- 客户提供删除按钮；存在关联票单时执行安全归档并撤销登录权限，保留历史数据。
- 不再存在业务员之间的客户交接，也不再提供从代理端反向批量分配客户的入口。

海外代理管理：

- 由业务员创建海外代理账号。
- 业务员可编辑显示名、重置密码、启用或停用账号。
- 海外代理停用后会撤销其内部登录会话，但历史业务记录保留。

票单录入与分配：

- 手工录入必须先选择已有客户，再填写票单；创建成功后自动绑定该客户。
- Excel 批量导入必须先选择客户；本次导入的所有成功票单自动绑定该客户。
- 批量追踪也必须先选择客户；成功查询或建立的票单自动绑定该客户。
- 三种入口均可选择“创建后立即发布给客户”；关闭时只建立草稿授权。
- 票单管理页保留单票立即更新、勾选批量更新和一键更新全部票单。
- 系统默认不执行每日自动更新，船司数据更新由唯一业务员手动触发。
- 更新任务弹窗展示总数、进度、成功、部分成功、失败、重试、错误码和具体失败项。

完整票单信息包括：

- 基础信息：承运人、单号类型、业务单号、Job、客户 PO、Client No./Name、订舱号、提单号、运输条款。
- 路线详情：POR、FPOL、LPOD、FND 四个节点必填，中转港可选。
- 预计与实际时间：ETD、ETA、预计最终到达、实际离港、实际到港和交付时间。
- 最新动态：当前阶段、事件名称、事件时间和事件地点。
- 分段运输：运输方式、船名/车辆、航次、装卸港及计划/实际时间。
- 箱型数量：箱型和数量；具体箱号、当前位置和箱状态可选。

### 2.3 海外代理工作台

- 使用内部账号通道登录，系统角色固定为 `OVERSEA_AGENT`。
- 只显示业务员分配给当前代理的客户和相关票单。
- 可查看路线、订舱、运输分段、箱型和箱号等业务详情。
- 可处理备注、票单文件和留言等协作内容。
- 不提供客户创建、客户删除、票单创建、发布、单票更新、批量更新或一键更新权限。
- 不能查看未分配客户及其票单。

### 2.4 标准信息列表

- 后台客户、票单、账号、设备、文件、审计、接口统计和 Excel 预览统一使用 Element Plus 表格。
- 表格使用方形边框，不使用卡片式大圆角。
- 表头、行高和单元格宽度保持适中；长内容使用合理最小宽度、滚动或省略提示。
- Excel 导入错误按工作表、Excel 行号、字段和原因展示，成功与失败项分开统计。

## 3. 外部客户货物追踪平台

- 客户使用用户名、密码和客户码登录。
- 总览展示已发布票单数量、在途状态和最近动态。
- 票单列表支持客户范围内的搜索、筛选和收藏。
- 票单详情展示路线节点、中转港、预计时间、最新动态、订舱信息、运输分段、箱型数量、箱号和运输状态。
- 客户只能读取业务员已经发布的数据，不能触发船司查询或修改内部业务信息。
- 客户可在授权票单范围内查看和上传文件、参与留言沟通。

## 4. 智能装箱计算平台

- 货物维护：单条录入、批量录入、CSV/Excel 导入、示例数据和清空重建。
- 货物参数：名称、尺寸、重量、数量、包装/分组，以及可堆叠、可旋转、承压和支撑等约束。
- 箱型配置：内尺寸、门尺寸、最大载重和可用性，支持常用普柜、高柜、冷藏柜和平板柜。
- 智能计算：在浏览器 Web Worker 中执行多策略三维装箱搜索。
- 方案比较：比较箱数、空间利用率、载重利用率、底面积利用率和综合参考成本。
- 安全校验：检查尺寸、门限、载重、旋转、堆叠、支撑、重心和重量平衡。
- 三维可视化：查看每个集装箱的摆放坐标、层次、剩余空间和装载进度。
- 结果输出：导出装箱明细、方案报告和可继续处理的数据文件。

## 5. 账号与数据规则

- 内部登录名：全局唯一。
- 内部密码：12–128 位，必须同时包含大写字母、小写字母、数字和特殊字符，且不能包含登录名。
- 客户登录名：全局唯一。
- 客户密码：至少 8 位，并按客户创建/导入界面的复杂度规则校验。
- 客户码：6–10 位，可使用字母、数字、点、下划线或连字符，必须全局唯一。
- 客户业务身份：发货人（`SHIPPER`）或收货人（`CONSIGNEE`）。
- 船司更新权限：仅业务员和管理员拥有；海外代理和外部客户均无权触发。

## 6. 推荐业务流程

1. 管理员初始化唯一业务员账号。
2. 业务员创建客户和海外代理账号。
3. 业务员在手工录入、Excel 导入或批量追踪前选择客户，系统自动创建客户票单授权。
4. 业务员按客户行直接分配或更换海外代理。
5. 海外代理处理被分配业务的文件、留言、备注和其他细节。
6. 业务员按需执行单票更新、批量更新或一键更新，并决定是否发布给客户。
7. 外部客户登录客户平台查看已经发布的最新业务数据。
