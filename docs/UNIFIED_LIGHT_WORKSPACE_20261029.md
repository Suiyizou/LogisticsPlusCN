# 统一浅色工作区与官网详情升级

## 工作区

内部页面共用OperationsEntry的认证与唯一WorkspaceShell。运输跟踪、装箱、业务和后台切换只替换右侧内容，侧栏保持固定宽度。顶层菜单按手风琴方式展开，当前页面自动展开所属组。移动端使用抽屉菜单，页头隐藏长姓名但保留完整可访问标签。

现有tracking保留独立运行能力，员工工作区以常驻的同源内容框架复用它；第一次进入才创建，切到其他内页时隐藏，不重建或重新设置源地址。父子消息均核对origin、source及允许的路由；嵌入模式仅使用员工会话，旧请求不能注销新会话或覆盖新选中的运单。

只有tracking HTML允许SAMEORIGIN与`frame-ancestors 'self'`；其他页面和API继续禁止被嵌入。个人资料、修改密码和工作偏好入口保留，沿用原API及会话隔离逻辑。

## 导入子页

- `/smart-import/excel`：原始工作簿、识别清单与按需展开的原图交叉核对。
- `/smart-import/image`：完整图片来源与逐项审阅。
- `/smart-import/text`：直接粘贴货物文本并识别审阅。

三页共用已有智能识别与原始证据校验，仍禁止硬性问题或跨源差异放行。旧`/excel`、`/smart-import`及`/planner/cargos?import=smart`迁移到独立Excel页；保留其他查询参数和锚点，使用replace避免返回循环。货物清单和设置页不再内嵌整套导入界面。

## 前台介绍

首页、产品概览、公司介绍和12个既有服务详情采用浅色摄影与文字面板。服务详情增加差异化概览、能力、流程、交付内容、应用场景、FAQ和行动入口，支持中英文。公司信息与服务范围基于现有项目，不添加虚构资质、客户背书或联系资料。

三份整页生成参考、提示词及使用范围记录在`output/ui-reference-20261029/`。参考图不作为整屏位图塞入产品，实际页面由Vue、CSS和已有素材构成。
