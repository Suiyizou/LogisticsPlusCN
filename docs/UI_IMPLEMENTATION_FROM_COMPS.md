# 整页设计图到可用界面的实施规格

日期：2026-10-28。决策与只读审查：Astra Ultra。实现：Sol High。本文只定义实现与验收规格，不代表页面已还原或已通过浏览器验收。

## 1. 本轮完成标准

用户最新要求是把整页生图落实到代码，并兼顾动效、字体、下拉与所有已有页面。图集不作为实现交付；仅修改全局颜色、边框与阴影也不算完成。必须修改代表页的实际区域排列、组件密度、图片区比例和交互状态，保持现有业务功能、数据、权限与路由。

唯一视觉参照为 `output/ui-full-design-20261028/01..08` 八张最终 PNG。04 仅使用 `04-tracking-files-ui.png`；`deprecated-04-mixed-detail-concept.png` 禁止参考。02 的实际页面是 `/services/planning`，不是运输详情。

生成图中的文字、样本计数、日期、财务菜单、社媒、备案及不存在的业务入口没有功能授权。保留图的视觉位置与层级，以真实业务文字、现有菜单、真实数值替换。不得将图整体铺成页面，也不得把三维结果替换为静态图。

## 3. 测量规则与共享视觉契约

以下坐标为对生图区域边界的视觉量测，按桌面宽 1440px 归一后取整，是可执行目标值，不声称源图有可恢复的设计稿矢量坐标。01/02 缩放因子为 `1440 / 1113 ≈ 1.294`；03/04/05/07/08 为 `1440 / 1513 ≈ 0.952`。

桌面验收基准：浏览器内容视口 1440 × 1000、缩放 100%、DPR 1；另检查 1280 × 900。公开页使用全页截图，预期长图约 1830px。06 桌面用 1440 × 900，手机用 390 × 844；不要把含桌面和手机的整个 1568px 画板当一张网页实现。

| ------------------ | ------------------------------ | ------------------------------------------------ |
| 主色/正文          | `#15384A` / `#132B3C`          | 延续当前 token                                   |
| 强调色             | `#BA4B25`，hover `#983A19`     | 推进入口、当前步骤、选中重点；不覆盖危险动作语义 |
| 背景/面板/线       | `#F2F5F6` / white / `#D9E2E6`  | 不靠大阴影分区                                   |
| 公开 hero 标题     | 64px，700，行高 1.24           | 36–40px，1.25；保持有意换行                      |
| 公开 section 标题  | 34px，650–700，1.35            | 26px                                             |
| 应用页 H1          | 32px，700，1.3                 | 26px                                             |
| 应用 section H2    | 20px，650，1.4                 | 18px                                             |

### 3.2 共享文件所有权

共享 token 的真实源文件是 `design-system/logisticspluscn-maritime/tokens.css`。`frontend/src/brand-tokens.css` 与 `tracking-service/public/brand-tokens.css` 是生成目标，不能分别手改。root 已确认 B 为唯一所有者；改完运行既有 `frontend/scripts/sync-brand-tokens.mjs`。A 与 C 不写共享 token。

共享组件 `WorkspacePageHeader.vue`、`workspacePageStyles.css`、`workspaceMotion.css`、公共 Element dialog 样式由 B 所有；C 的业务页通过局部 class 或 CSS 变量适配，不改变其全站默认规则。A 只改 public/auth 命名空间。禁止用未限定的 `h1`、`.card`、`select`、`.el-dialog` 或全局 `!important` 堆叠还原某一页。

### 3.3 动效与交互契约

已有 ui-ux-pro-max 数据库检索辅助确认：减少动效偏好必须生效，单视图只保留 1–2 类关键动效，进入 ease-out、退出 ease-in。视觉目标仍以用户图稿为准。

| 场景               | 目标动效                                                | 必须保留的行为                                                  |
| ------------------ | ------------------------------------------------------- | --------------------------------------------------------------- |
| 按钮/行 hover      | 160–180ms 色彩、边框；卡片最多上移 2px                  | 不改变点击区域或表格行高                                        |
| 页面主要内容进入   | 280–320ms opacity + translateY(12px)，同组 stagger 40ms | 不让所有内容依赖动画结束才可见                                  |
| 菜单/下拉          | 180ms，translateY(6px) + opacity                        | 首次方向键打开就能聚焦；Escape/外点关闭；焦点样式清楚           |
| 抽屉               | 260–280ms，右侧 translateX(24px) + opacity              | 正确 modal/inert、滚动锁、关闭后回焦；不靠猜测 timeout 定位焦点 |
| 弹窗               | 220ms，translateY(12px) + opacity                       | 退出期间内容 inert；已有表单/错误/保存行为不变                  |
| 公共 hero/入口插画 | 首次 400–500ms 单次轻微出现                             | 不使用循环漂浮、自动轮播或大幅视差                              |
| 图表               | 280–360ms 数据进入                                      | 真实数值、图例及坐标语义不变；数据更新不重复整页动画            |

`prefers-reduced-motion: reduce` 时去掉位移、stagger、连续效果，保持即时状态反馈。不要为静态动效引入新重量级动画依赖。
