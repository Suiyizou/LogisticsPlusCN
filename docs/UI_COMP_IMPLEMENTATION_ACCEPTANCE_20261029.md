## 样式与动效

统一深海蓝/陶土橙、6px卡片圆角、细边线、表单焦点、自托管Inter/Noto Sans SC。动画已在代码中实现：hero轻量进入、卡片分组出现、mega展开、菜单/抽屉/弹窗进退、按钮/卡片hover、工作台SVG航线以及实际计算进度。各端保留减少动效偏好，不用动画伪造业务状态。

本轮实测修复了列表列宽遮挡状态/日期、抽屉目的港竖排、工作台卡片过疏、3D重心卡错误绝对定位、结果汇总被旧翻译缓存覆盖、后台手机导航撑宽整页、后台页签翻译键和刷新按钮旧文案。

## 文件预览

两端改为本地PDF.js canvas，固定6.4.299及同版本legacy worker/辅助资源；不放宽CSP或使用外部预览服务。既有鉴权、下载、关闭/换文件/会话代际取消保留。绘制静态盖章、批注及已填写字段外观，不创建互动注释/表单层。

浏览器实际看到了本地样本的中文正文、英文、第二页扫描图，验证翻页、1440→390适宽和关闭回焦；Vue管理端也完成第二页与缩放同时触发的实测，最终停留第二页，关闭后画布移除。另有真实静态Stamp/填写字段AP像素正负对照及翻页/resize竞态回归。详见 `docs/PDF_LOCAL_PREVIEW.md`、`docs/TRACKING_PDF_PREVIEW_20261028.md`。

主预览为独立 `cargo-ui-preview` 五服务：frontend、gateway、Java backend、MySQL、tracking。已导入用户SQL并完成Flyway V1–V5；原5名员工密码字段逐项保持不变。当前7员工/11客户/54票单/114快照/48刷新任务/12附件元数据含明确新增的本地验收样本。原数据库、原SQL与旧Docker项目未覆盖。

- 原附件只随SQL提供元数据，缺失的历史二进制仍需原文件；本地PDF/TXT样本和1条验收留言均明确标注来源。
- 定时更新任务按用户要求为设计预览，未连接状态接口，数值用`—`，不声称调度真实运行。
- 本地自动刷新、补查重试与数据库事件关闭，服务网络隔离；人工样票缺补查字段时，既有补查失败提示如实显示，不能冒充船司查询成功。
