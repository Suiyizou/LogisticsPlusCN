# 客户资料与真实全链路验收

日期：2026-10-14。本轮承接模块平台改造，补齐浏览器 → Java API → MySQL 的真实链路，并将客户资料作为现有业务模块迁移样板。

## 已完成的业务迁移

客户新增、详情和修改使用明确的 `CustomerProfileResponse`，前端新增/修改通过 OpenAPI 类型客户端。响应不会返回密码散列、密码盐或数据库客户主键；客户码仍按既有明确建档操作返回，普通资料读取/修改不返回一次性明码。

增加可选 `contactEmail`：创建弹窗、编辑弹窗、客户详情、目录查询和搜索均贯通，后端校验长度和格式。V5 只增加可空列，旧客户保留原标识、备注、身份和密码。

客户资料沿用既有 PATCH 语义：字段省略或 null 保留原值；空字符串清空可空文本。修复编辑窗口清空备注却发送 null 的问题。新参考模块的存在性 PATCH 仍使用另一套已明确约定的 null 清空语义，不能混用。

保留客户资料的负责人写入限制、管理员权限、客户码变化撤销会话、角色变更约束、同事务审计，以及系统只允许一个业务员账号的规则。普通更新响应保留已分配员工信息，避免前端显示丢失关联。

真实浏览器还发现并修复：员工登录丢失受保护模块深链接；邮箱占位文案的 @ 被翻译编译器解释为链接；客户读取 JSON 期间切换账号时，旧响应仍可能进入新会话。

## 可重复的真实环境

前提：Node 20+、Java 17、Docker Engine、已缓存或可拉取 mysql:8.4。

```bash
mvn -f backend/pom.xml package
npm run verify:e2e
```

脚本创建随机名称和所有权标签的 MySQL 容器，端口仅绑定本机。它从 V4 结构准备历史客户，升级 V5，再通过真实 HTTP 验证登录、新增、修改、无效值拒绝、重复冲突、负责人范围、企业票单隔离、凭据隔离及应用重启后的持久化。结束时只清理自己创建的 Java 进程、MySQL 容器和匿名卷。

它先复制固定 JAR 到专用目录，再运行副本，避免 Windows 锁住 backend/target 中的构建文件。报告写入 `.tmp/<随机验收名>/report.json`，记录 JAR SHA-256，不输出数据库口令和会话令牌。

人工浏览器验收模式：

```bash
npm run verify:e2e -- --serve --work .tmp/manual-e2e
# 如已有上一版本的可执行 JAR，可额外使用：
npm run verify:e2e -- --serve --before-jar /path/to/previous.jar --work .tmp/upgrade-e2e
```

`--serve` 启动真实 Vite 页面，后端代理指向专用 Java 端口；Vite 缓存独立，避免与其他测试/构建干扰。根据控制台 READY 提示读取 browser-environment.json，使用其中的虚构测试账号操作。完成后在该 work 目录创建 `stop` 文件，并等待脚本完成清理。不要在结束脚本前强制关闭终端。

这不是模拟 API。自动入口验证 HTTP/MySQL；本次浏览器操作另使用 Playwright CLI，通过真实界面完成登录、建档、修改、清空、刷新、客户票单读取和退出。没有把浏览器模拟接口的结果冒充真实数据库链路。

- 后端：264 项 / 34 套测试通过；最终可执行 JAR 打包成功。
- 前端：592 项行为测试通过；48 个 SFC 严格类型检查、94 项端口负例、8 项 API 负例通过；生产构建通过。
- 模块生成与接口契约：24 项通过，生成物无漂移。
- 默认真实 E2E：9 项通过，包含清理；上一版真实 JAR 创建客户后升级到当前 V5 的演练也通过。
- V5 数据库矩阵：空库、合成旧库及桌面 SQL 副本升级通过，源 SQL 哈希不变；这是隔离副本，不是生产升级。
- 浏览器：真实新增和修改后的客户行直接在专用 MySQL 中核对；客户仅看见自己的已发布票单；请求不携带员工令牌；退出后刷新保持退出；深链接和查询参数在登录后保留。

## 后续开发规则

新增内部参考模块继续使用 module:create；已存在的复杂客户/订单模块按 DTO → 业务用例 → 受控 Repository → 注册页面逐步迁移，不让脚手架接管历史表。本次 V5 是历史业务表的审核后增量迁移，未宣称由内部参考模块生成器自动完成。

修改已有业务字段时，同步明确请求语义、公开响应、读取投影、表单、类型契约和数据库迁移；增加可空列优先，收紧约束和删除字段分阶段完成。权限、审计与生命周期规则保留专门用例。

远端 Gitee 流水线、测试服务器的完整部署及备份恢复演练尚未执行；本轮没有触发生产发布。
