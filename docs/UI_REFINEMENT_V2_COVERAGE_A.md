## 已实现范围

- 公开轻量入口现在覆盖 /、/services、/services/:slug，保留旧 /#/ 及 /#admin 分流。新增公开路由不改变受保护工作区的认证。
- 单一服务展示 catalog 消费当前启用模块及角色 metadata，不替代业务模块 registry。匿名进入受保护工具时仍走既有登录；缓存角色不匹配时提供可达工作区入口。
- 全宽三列 mega 导航、右侧定高预览卡、120ms hover 意图、140ms 离开关闭、焦点联动、Escape 返回触发器、外点关闭、手机分组手风琴与登录/语言入口。
- 桌面查询 PublicSelect 是轻量只读 combobox/listbox：方向键、Home/End、Enter/Space、Escape、Tab、字母检索、选中态、禁用/空态及外点关闭；手机和触屏保留真正 native select。原查询参数及船司能力边界不变，不引入 Element Plus 至公开查询组件。
- 官网首屏一次性轻微入场、滚动区一次性渐入、菜单与预览内容过渡；reduced motion 取消位移、缩放和错峰，保留至多80ms状态淡入。
- 共享44px控件、6/10/12px圆角、Element Plus选择框/可搜索多选/下拉菜单/日期/pagination皮肤，含38px选项、局部滚动、hover/selected/focus/disabled与清楚的输入边框。
- Inter Variable 与 Noto Sans SC Variable 自托管，保留正常字形全部发行分片及 OFL，按unicode-range加载；仅预加载Latin，不请求字体CDN。字体唯一源 frontend/public/fonts，追踪端由 sync-brand-fonts.mjs 同步。
- 三张生成品牌图已接入并等比例输出WebP响应尺寸。来源及非企业实拍属性记录于 frontend/public/brand/v2/README.md；产品页面不放水印式生成免责声明，不将图像声称为企业现场。
- 登录保留员工/客户真实API、客户码、错误处理及回跳；刷新排版、字重与影像，保持真实异步等待、可读错误和重试。
