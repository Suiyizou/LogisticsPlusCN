# Logistics map geography

The map uses an offline, curated port catalog. A marker is a port reference point, not a terminal coordinate, an AIS position or a vessel location.

The current UI shows a compact, lazy-loaded map only in shipment details. The overview does not fetch extra shipment pages for mapping. The map is built from the selected shipment's snapshot, with unresolved places available in its node list.

Country-only aliases for the imported air/inland records are intentionally separate from the map's port catalog: `SHA` (Shanghai), `IAH` (Houston), and `TUL` / `Tulsa` (Oklahoma). They allow a country flag without inventing a maritime route, port coordinates or a UN/LOCODE. References checked 2026-11-04: [China Eastern's Shanghai/SHA selector](https://ca.ceair.com/en/member-home.html), [Houston Airports' IAH visitor information](https://www.fly2houston.com/app/app/app-visitor-information/), and [FAA Tulsa airport information](https://www.faa.gov/flight_deck/tul). Explicit country values retain precedence; contradictory inferred locations remain unresolved.

- Coordinates come from the U.S. National Geospatial-Intelligence Agency [World Port Index](https://msi.nga.mil/Publications/WPI) ([source CSV](https://msi.nga.mil/api/publications/download?key=16920959%2FSFH00000%2FUpdatedPub150.csv&type=view)), retrieved 2026-11-03 and rounded to five decimal places. This selection covers the ports in the existing tracking import and common ports across other trade lanes.
- The node keys use [UNECE UN/LOCODE](https://unlocode.unece.org/publications/) country and location identifiers. A few WPI records are indexed under a different code for the same named port area; their coordinates are retained but the tracking model uses the UN/LOCODE city keys for Shanghai (CNSHA), Ningbo (CNNGB), Dalian (CNDLC), Xiamen (CNXMN), Guangzhou (CNGZG) and Fuzhou (CNFOC). Singapore (SGSIN) uses the [UNECE Singapore listing](https://service.unece.org/trade/locode/sg.htm) coordinate of 0117N 10351E.
- Names and translations in the catalog are explicit local aliases. An ambiguous alias needs a recognized country or subdivision, and a contradictory country or location code cannot select a catalog point. Locations outside the catalog can appear when the record supplies a valid, named latitude/longitude pair; otherwise they are listed as unresolved. No external geocoder is contacted.
- Edges represent relationships between carrier reported route or leg endpoints, with shipment origin/destination as a fallback when no route relation is present. They show the shorter longitude crossing and split at the international date line. They do not show a navigational path, sea distance, progress, or live position.
