## 本轮修复

1. 员工旧请求在身份切换后才返回 401，会清除新账号会话；旧成功响应也可能污染新页面。
   JSON、下载及异步读取现在核对发起请求时的身份，保留退出登录和 FormData 上传兼容性。
2. COSCO 补充详情漏检配置浏览器代理后的内部授权。主查询和补充查询现在共用鉴权规则。
3. COSCO AUTO 的缓存及进行中请求未区分代理授权范围。现在有效授权与公共请求隔离，
   匿名及错误 key 无法复用授权结果；原始 key 不进入缓存标识。
4. 备份可能从滞后的 `.env` 记录错误镜像标签，导致后续恢复到不匹配的代码。
   现在从实际运行容器采集标签和镜像 ID；回滚优先使用已校验的镜像清单，兼容旧备份格式。
   混合 release 会在导出数据库之前被拒绝。
5. CI 镜像阶段改为显式 Docker CLI 构建上下文：追踪服务用 `tracking-service`，前后端用根目录。
   同时补充首次安装外部数据卷、管理员初始化和历史库接管说明。
