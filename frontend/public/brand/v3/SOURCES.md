# 登录场景来源

`login-port-reference.webp`由内置imagegen依据用户认可的整页登录参考重建为纯摄影概念图，再仅做WebP编码优化，未改变像素尺寸或构图。

原始生成文件、完整提示词与哈希记录保存在项目`output/ui-reference-fidelity-20261029/`。本图为生成的港口场景，不是公司自有场地的纪实照片；不作为实际船舶、港口位置或业务状态证据。

## 公开首页港口主图

`terminal-editorial.jpg` 由内置 imagegen 根据 Astra 拟定的公开首页主图提示词生成。提示词要求以斜俯视角度呈现现代集装箱码头，将靠泊的无标识货船放在画面右侧，左侧留出开阔的海面与天空。原始 PNG 以 JPEG 质量 87 重新编码，保留 1536 × 1024 的尺寸。此图为港口概念场景。
