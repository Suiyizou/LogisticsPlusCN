# V2 品牌氛围图

maritime.png、loading.png、collaboration.png 为本轮生成的独立横向图像，分别用于运输、装载准备及文件协作的视觉氛围。它们不代表公司的现场照片、自有设备、客户案例或办公团队。

原始 PNG 保留为来源。640/1280/1920 命名的 WebP 为同一图像的等比例尺寸与压缩版本，未重新绘制或改变内容；实际最大宽度受原图限制。官网 hero 使用 maritime，装箱和箱型详情使用 loading，客户、业务及文件协作使用 collaboration。生成来源记录于本 README；产品页面采用场景描述性 alt，不将图像表述为企业实拍。正文和品牌标识均由 HTML 呈现。
